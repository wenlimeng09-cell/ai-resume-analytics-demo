# AI 简历助手用户转化与运营分析

## 数据分析岗位

- 使用 Python、pandas 和 Plotly 分析 900 名模拟用户的 8,007 条行为事件，按任务串联从访问到报告导出的六步漏斗，并支持按用户去重、按人群筛选。
- 在 774 个已采纳建议的任务中定位到 403 个未导出，环节流失率为 52.1%。区分采纳后导出率（371/774）与有效优化任务完成率（371/794），在看板中展示分子和分母。

## 商业分析岗位

- 围绕“有限的试点资源应先覆盖哪类用户”，按人群拆解模拟任务的流失量与转化率。应届生采纳后未导出的任务最多（151 个），转行用户采纳后导出率最低（97/218，44.5%）。
- 分别提出覆盖流失任务和调查低转化原因的试点方向，设计按组衡量增量完成任务数的验证方案。

## 运营岗位

- 从 3,618 条模拟建议中比较不同内容类型的处理结果，发现“项目表达”建议的拒绝量和拒绝率均最高（267/794，33.6%），据此选择优先抽查的模板。
- 设计模板改写对照试验，以同类建议的采纳率衡量效果，同时跟踪待处理率、抽检新增经历是否有原文依据。保留未填写的拒绝原因，避免误读用户反馈。
