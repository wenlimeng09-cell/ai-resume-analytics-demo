# AI 简历优化助手｜产品数据分析项目

- 使用 Python、pandas、Streamlit 和 Plotly 搭建交互原型与分析看板，支持输入简历和岗位描述、生成基于规则的修改建议、记录采纳选择及导出报告。
- 基于 900 名模拟用户的 8,007 条事件，按同一任务内的事件顺序构建六步漏斗。774 个任务至少采纳了一条建议，其中 371 个导出了报告，采纳至导出环节流失 52.1%。据此将采纳后的导出引导列为优先验证项。
- 比较两组模拟建议模板的采纳表现，展示建议数、采纳数和组间差异。将“至少采纳一条且导出报告的任务占已生成任务的比例”定义为核心指标，便于后续评估流程调整。

## 一句话版本

搭建简历优化原型与产品分析看板，使用 8,007 条模拟事件还原从访问到导出的任务漏斗，定位采纳后未导出的 403 个任务，并设计导出引导的验证指标。
