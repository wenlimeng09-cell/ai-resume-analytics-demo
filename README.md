# AI 简历助手用户转化与运营分析

[在线体验四页作品集](https://ai-resume-ai-pm-demo.streamlit.app/)

**774 个任务至少采纳了一条简历建议，其中 371 个导出报告，403 个没有导出。** 作品集使用固定模拟日志还原用户路径，比较不同调查目标对应的优先人群，并设计可以用真实数据验证的运营试点。工具页可体验生成、采纳、拒绝和下载的过程。

| 页面 | 分析过程 |
| --- | --- |
| 业务概览 | 从原始事件计算采纳后导出率，给出分子、分母和观察期，展示流失定位、人群比较、内容筛选三项分析。 |
| 转化与人群分析 | 同一任务按时间顺序还原六步漏斗，支持按人群筛选、切换任务与去重用户口径，并比较各人群的流失量与导出率。 |
| 运营诊断与验证 | 对照各类建议的生成、采纳、拒绝与待处理数量，为采纳后导出引导和项目表达模板设计对照试验及护栏指标。 |
| 工具体验与数据说明 | 使用数分、商分、运营示例或上传脱敏简历，查看岗位依据及修改清单。可切到表结构、指标算法与样本边界。 |

## 样本与口径

已用[原始模拟生成版本](https://github.com/wenlimeng09-cell/ai-resume-analytics-demo/tree/4de4961c3cdb475aa688729ecf67607540d761ac/data)重新生成样本，并逐字节核对五张 CSV。数据说明页提供 SQLite 对账，从任务表独立复核每类人群的事件统计。

五张 CSV 含 900 名用户、8,007 条事件、794 个生成任务、3,618 条建议及 143 份模拟反馈。访问任务从事件表还原，同一用户可针对多个岗位发起任务。任务漏斗依次到达 1,250、1,086、888、794、774 和 371 个任务。建议采纳率的分母为已生成建议条数，数据中没有独立的曝光事件。

- 采纳后导出率为 371 / 774 = 47.9%。有效任务完成率为 371 / 794 = 46.7%，从全体已生成任务开始计算。
- 应届生的未导出任务最多（151 个），转行用户的采纳后导出率最低（97 / 218 = 44.5%）。对照真实试点的增量和成本后，才能判断投入回报。
- 项目表达类有 267 / 794 条建议被明确拒绝。建议表没有拒绝原因字段，工具中的反馈属于当前会话。
- 样本生成器预设了模板组之间的概率差异。已有 A/B 分组用于演示计算，两项新的运营试验仍是待验证方案。

## 运行项目

从此分支的仓库根目录执行以下命令，推荐 Python 3.12。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app_ai_pm.py
```

回归测试使用 `python -m unittest discover -s tests -v`。发布站点使用分支 `codex/ai-pm-public-demo`，Streamlit 入口为 `app_ai_pm.py`。五张固定样本表随仓库提供，启动无需重新生成。

## 简历工具与可选模型

规则引擎可直接体验。输入支持粘贴或导入含文字层的 PDF、DOCX、TXT、MD。工具从简历原文与岗位要求生成诊断，覆盖率只度量可识别关键词。采纳、拒绝、暂不处理和自愿填写原因保存在当前会话。导出报告包含修改建议和处理状态。工具不会将个人输入加入演示样本。

要启用模型体验，可在 Streamlit Secrets 或环境变量中设置 `DEEPSEEK_API_KEY`、`DEMO_ACCESS_CODE`，并按需设置 `DEEPSEEK_MODEL` 与 `MAX_LLM_CALLS_PER_SESSION`。默认模型为 `deepseek-v4-flash`。主动选择并解锁模型后，简历和岗位描述会发送给 DeepSeek，应使用虚构或已脱敏的文本。响应无法通过校验或请求失败时，页面标明已使用规则回退。

## 代码与资料

- `analysis_data.py`、`conversion_view.py` 还原任务路径并比较人群。
- `operations_view.py` 统计建议处理结果、分组模拟数据并展示实验设计。
- `tool_view.py` 与 `logic/` 处理简历导入、诊断生成、反馈和报告。
- `outputs/` 提供项目说明、三个岗位侧重的简历写法和面试讲述稿，另保留原始设计草案。
